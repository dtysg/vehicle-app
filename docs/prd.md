# 需求文档

## 1. 应用概述

### 1.1 应用名称
油价通

### 1.2 应用描述
一款基于Expo + React Native开发的移动端油价查询工具，用户可切换不同城市查看对应的92#、95#、0#柴油等油品的零售价、调价历史和调价预测信息。选中的城市本地持久化保存，下次打开自动加载上次选择的城市。同时提供国际原油5天活动均价统计功能，展示布伦特、WTI、阿曼/米纳斯原油近5日移动均价及价格走势。

## 2. 用户与使用场景

### 2.1 目标用户
需要了解本地油价信息的车主或驾驶员

### 2.2 核心使用场景
- 用户需要查询当前所在城市的最新油价
- 用户计划出行前查询目的地城市的油价
- 用户关注油价调整趋势，查看历史调价记录
- 用户希望了解未来油价调整预测
- 用户关注国际原油价格走势，查看近5日活动均价

## 3. 页面结构与功能说明

### 3.1 页面结构

```
油价通
├── 油价查询页面(首页)
├── 城市选择页面
├── 调价历史页面
├── 调价预测页面
└── 5天活动均价页面
```

### 3.2 功能说明

#### 3.2.1 油价查询页面(首页)

**页面功能**
- 展示当前选中城市名称
- 提供城市切换入口按钮
- 展示当前城市的油品零售价信息
- 提供查看调价历史入口
- 提供查看调价预测入口
- 提供查看5天活动均价入口

**城市切换功能**
- 用户点击城市名称或切换按钮，跳转至城市选择页面
- 切换城市后，页面自动刷新显示新城市的油价信息
- 选中的城市本地持久化保存

**油价信息展示**
- 展示92#汽油零售价
- 展示95#汽油零售价
- 展示0#柴油零售价
- 展示数据更新时间
- 若当前城市无独立数据，显示全国基准价并标注「该城市暂无独立数据,显示全国基准价」

**调价历史入口**
- 用户点击调价历史按钮，跳转至调价历史页面

**调价预测入口**
- 用户点击调价预测按钮，跳转至调价预测页面

**5天活动均价入口**
- 用户点击5天活动均价按钮，跳转至5天活动均价页面

#### 3.2.2 城市选择页面

**页面功能**
- 展示支持的城市列表
- 标识当前选中的城市
- 提供返回按钮

**城市列表**
- 支持的城市包括：北京、上海、天津、广东、江苏、浙江、山东、河北、四川、湖北
- 城市按列表形式展示
- 当前选中城市高亮显示

**城市选择功能**
- 用户点击城市名称，选中该城市
- 系统将选中城市保存至本地存储
- 自动返回油价查询页面，刷新显示新城市的油价信息

#### 3.2.3 调价历史页面

**页面功能**
- 展示当前选中城市的历史调价记录
- 提供返回按钮

**历史记录展示**
- 按时间倒序展示调价记录
- 每条记录包含：调价日期、92#汽油价格、95#汽油价格、0#柴油价格、调价幅度
- 调价幅度标注上涨或下跌
- 若当前城市无独立数据，显示全国基准调价历史并标注「该城市暂无独立数据,显示全国基准历史」

#### 3.2.4 调价预测页面

**页面功能**
- 展示当前选中城市的油价调整预测信息
- 提供返回按钮

**预测信息展示**
- 展示预计调价日期
- 展示预测调价幅度
- 展示预测调价方向(上涨/下跌/搁浅)
- 展示预测依据说明
- 若当前城市无独立数据，显示全国基准预测并标注「该城市暂无独立数据,显示全国基准预测」

#### 3.2.5 5天活动均价页面

**页面功能**
- 展示布伦特、WTI、阿曼/米纳斯原油近5个交易日的活动均价
- 展示价格走势图表
- 展示当前价与5日均价的偏离情况
- 提供手动刷新按钮
- 提供返回按钮

**活动均价展示**
- 展示布伦特原油5日活动均价（美元/桶或元/桶）
- 展示WTI原油5日活动均价（美元/桶或元/桶）
- 展示阿曼/米纳斯原油5日活动均价（美元/桶或元/桶）
- 展示对应的折算每升价格
- 展示数据更新时间

**价格走势图表**
- 展示近5个交易日的价格走势（折线图或柱状图）
- 图表包含布伦特、WTI、阿曼/米纳斯三条曲线或三组柱状
- 横轴为交易日期，纵轴为价格

**偏离情况标注**
- 标注布伦特当前价与5日均价的偏离（高于/低于均价，偏离幅度）
- 标注WTI当前价与5日均价的偏离（高于/低于均价，偏离幅度）
- 标注阿曼/米纳斯当前价与5日均价的偏离（高于/低于均价，偏离幅度）

**手动刷新功能**
- 用户点击刷新按钮，重新获取最新的5日活动均价数据
- 刷新成功后更新页面展示内容

## 4. 业务规则与逻辑

### 4.1 城市数据规则

**支持城市列表**
- 北京、上海、天津、广东、江苏、浙江、山东、河北、四川、湖北

**数据获取规则**
- 优先获取城市独立油价数据
- 若城市无独立数据，使用全国基准价并标注
- 数据来源于免费数据源

**兜底策略**
- 当城市无独立实时数据时，显示全国基准价
- 在页面明确标注「该城市暂无独立数据,显示全国基准价」
- 调价历史和调价预测同样使用全国基准数据并标注

### 4.2 城市持久化规则

**保存规则**
- 用户选择城市后，立即保存至本地存储
- 保存内容为城市名称

**加载规则**
- 用户打开App时，自动读取本地存储的城市信息
- 若本地无保存记录，默认显示天津
- 加载成功后，自动获取该城市的油价信息

### 4.3 油价信息更新规则

**更新时机**
- 用户打开App时自动获取最新油价
- 用户切换城市时自动获取新城市油价
- 用户手动刷新时重新获取油价

**数据展示规则**
- 展示92#汽油、95#汽油、0#柴油的零售价
- 价格单位为元/升
- 展示数据更新时间

### 4.4 5天活动均价规则

**数据获取规则**
- 获取布伦特、WTI、阿曼/米纳斯原油近5个交易日的价格数据
- 数据来源于FRED等免费国际原油数据源
- 计算5日移动均价

**活动均价计算规则**
- 活动均价 = 近5个交易日价格之和 / 5
- 价格单位为美元/桶或元/桶
- 折算每升价格 = 桶价 / 158.98（1桶约等于158.98升）

**偏离情况计算规则**
- 偏离幅度 = (当前价 - 5日均价) / 5日均价 × 100%
- 当前价高于5日均价时，标注「高于均价」
- 当前价低于5日均价时，标注「低于均价」

**数据更新规则**
- 用户进入5天活动均价页面时自动获取最新数据
- 用户点击刷新按钮时重新获取数据

## 5. 异常与边界情况

| 场景 | 处理方式 |
|---|---|
| 网络异常导致油价获取失败 | 提示「网络异常,请稍后重试」,保留上次成功获取的数据 |
| 数据源异常导致油价获取失败 | 提示「数据获取失败,请稍后重试」 |
| 本地存储读取失败 | 默认显示天津油价 |
| 本地存储保存失败 | 提示「城市保存失败」,但仍允许查看当前城市油价 |
| 城市无独立数据 | 显示全国基准价,并标注「该城市暂无独立数据,显示全国基准价」 |
| 调价历史数据为空 | 显示「暂无调价历史记录」 |
| 调价预测数据为空 | 显示「暂无调价预测信息」 |
| 5天活动均价数据获取失败 | 提示「数据获取失败,请稍后重试」 |
| 5天活动均价数据不足5个交易日 | 使用实际可获取的交易日数据计算均价,并标注实际天数 |
| 手动刷新5天活动均价失败 | 提示「刷新失败,请稍后重试」,保留上次成功获取的数据 |

## 6. 验收标准

1. 用户打开应用,进入油价查询页面,显示上次选择的城市油价(首次打开默认显示天津)
2. 用户点击城市切换按钮,进入城市选择页面
3. 用户选择北京,系统保存选择并返回油价查询页面
4. 页面显示北京的92#、95#、0#柴油零售价及更新时间
5. 用户点击5天活动均价按钮,进入5天活动均价页面
6. 页面展示布伦特、WTI、阿曼/米纳斯原油5日活动均价、折算每升价格、价格走势图表及偏离情况
7. 用户点击刷新按钮,页面更新最新的5日活动均价数据
8. 用户关闭App后重新打开,自动显示北京油价
