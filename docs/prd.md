# 需求文档

## 1. 应用概述

### 1.1 应用名称
车辆信息系统查询通

### 1.2 应用描述
一款基于Expo + React Native开发的移动端车辆信息查询与管理工具，用户通过拍照识别或手动输入车牌号查询车辆信息，并可对车辆信息进行新增、编辑、删除操作。数据来源于Supabase数据库，包含汽油车辆、柴油车辆、LNG车辆共364条数据。

## 2. 用户与使用场景

### 2.1 目标用户
需要快速查询车辆信息的工作人员或管理人员

### 2.2 核心使用场景
- 现场查询车辆信息时，通过拍照识别车牌号快速获取车辆详情
- 办公场景下，通过手动输入车牌号查询车辆信息
- 需要确认车辆所属单位、车型、油品类型等信息时
- 车辆信息发生变化时，直接在App内新增、编辑或删除车辆记录

## 3. 页面结构与功能说明

### 3.1 页面结构

```
车辆信息系统查询通
├── 查询页面(首页)
├── 查询结果页面
├── 新增车辆页面
├── 编辑车辆页面
└── 删除车辆页面
```

### 3.2 功能说明

#### 3.2.1 查询页面(首页)

**页面功能**
- 提供拍照识别车牌号入口
- 提供手动输入车牌号搜索框
- 展示应用名称和简要说明
- 提供新增车辆入口按钮
- 提供删除车辆入口按钮

**拍照识别功能**
- 用户点击拍照按钮，调用设备相机拍摄车牌照片
- 将照片上传至百度OCR进行车牌号识别
- 识别成功后自动填充车牌号到搜索框，并触发查询
- 识别失败时提示用户重新拍照或手动输入

**手动输入功能**
- 用户在搜索框中输入车牌号(支持部分输入)
- 点击搜索按钮触发查询
- 支持模糊搜索，车牌号部分匹配即可返回结果

**新增车辆入口**
- 用户点击新增车辆按钮，跳转至新增车辆页面

**删除车辆入口**
- 用户点击删除车辆按钮，跳转至删除车辆页面

#### 3.2.2 查询结果页面

**页面功能**
- 展示查询到的车辆完整信息
- 显示车辆所属类别(汽油车辆/柴油车辆/LNG车辆)
- 提供返回查询页面的入口
- 提供编辑车辆信息入口按钮
- 提供删除车辆信息入口按钮

**信息展示规则**
- 根据车辆所属类别，展示对应的字段信息：
  - 汽油车辆：序号、单位、车牌号、车型、车身颜色、所用油品、汽油标号、所用油卡
  - 柴油车辆：序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡
  - LNG车辆：序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡、备注
- 未查询到结果时，提示「未找到该车牌号对应的车辆信息」

**编辑车辆功能**
- 用户点击编辑按钮，跳转至编辑车辆页面，携带当前车辆信息

**删除车辆功能**
- 用户点击删除按钮，弹出二次确认弹窗
- 用户确认后，从数据库中删除该车辆记录
- 删除成功后返回查询页面，提示「删除成功」

#### 3.2.3 新增车辆页面

**页面功能**
- 提供车辆类别选择(汽油车辆/柴油车辆/LNG车辆)
- 根据选择的车辆类别，展示对应的表单字段
- 提供保存按钮和取消按钮

**表单字段**
- 汽油车辆：序号、单位、车牌号、车型、车身颜色、所用油品、汽油标号、所用油卡
- 柴油车辆：序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡
- LNG车辆：序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡、备注

**保存功能**
- 用户填写完表单后，点击保存按钮
- 系统将新车辆信息保存至对应的数据表(gasoline_vehicles/diesel_vehicles/lng_vehicles)
- 保存成功后返回查询页面，提示「新增成功」

**取消功能**
- 用户点击取消按钮，返回查询页面，不保存数据

#### 3.2.4 编辑车辆页面

**页面功能**
- 展示当前车辆的所有字段信息，允许用户修改
- 提供保存按钮和取消按钮

**表单字段**
- 根据车辆类别展示对应字段，字段内容预填充当前车辆信息
- 汽油车辆：序号、单位、车牌号、车型、车身颜色、所用油品、汽油标号、所用油卡
- 柴油车辆：序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡
- LNG车辆：序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡、备注

**保存功能**
- 用户修改字段后，点击保存按钮
- 系统更新数据库中该车辆的信息
- 保存成功后返回查询结果页面，提示「修改成功」

**取消功能**
- 用户点击取消按钮，返回查询结果页面，不保存修改

#### 3.2.5 删除车辆页面

**页面功能**
- 提供车牌号输入框
- 展示查询到的车辆完整信息
- 提供删除按钮和取消按钮

**查询功能**
- 用户在输入框中输入车牌号(支持部分输入)
- 系统自动在3个数据表中查询车牌号
- 支持模糊匹配，车牌号部分相同即返回结果
- 查询到车辆后，展示车辆完整信息及所属类别
- 未查询到结果时，提示「未找到该车牌号对应的车辆信息」

**信息展示规则**
- 根据车辆所属类别，展示对应的字段信息：
  - 汽油车辆：序号、单位、车牌号、车型、车身颜色、所用油品、汽油标号、所用油卡
  - 柴油车辆：序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡
  - LNG车辆：序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡、备注

**删除功能**
- 用户确认车辆信息无误后，点击删除按钮
- 系统弹出二次确认弹窗，提示「确认删除该车辆信息？」
- 用户点击确认按钮
- 系统从数据库中删除该车辆记录
- 删除成功后返回查询页面，提示「删除成功」

**取消功能**
- 用户点击取消按钮，返回查询页面，不执行删除操作

## 4. 业务规则与逻辑

### 4.1 数据来源与结构

**数据存储**
- 车辆信息已从Excel文件导入Supabase数据库
- 数据库包含3个数据表，对应Excel的3个工作表

**数据表结构**

| 数据表名称 | 数据量 | 字段列表 |
|---|---|---|
| gasoline_vehicles(汽油车辆) | 285条 | 序号、单位、车牌号、车型、车身颜色、所用油品、汽油标号、所用油卡 |
| diesel_vehicles(柴油车辆) | 74条 | 序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡 |
| lng_vehicles(LNG车辆) | 5条 | 序号、单位、车牌号、车型、车身颜色、所用油品、所用油卡、备注 |

### 4.2 查询逻辑

**查询流程**
1. 用户输入车牌号(拍照识别或手动输入)
2. 系统在3个数据表中同时查询车牌号字段
3. 支持模糊匹配，车牌号部分相同即返回结果
4. 返回匹配到的车辆信息及所属类别

**查询规则**
- 车牌号不区分大小写
- 支持部分车牌号匹配(如输入「京A」可匹配所有京A开头的车牌)
- 同一车牌号在不同数据表中不会重复

### 4.3 OCR识别规则

**识别流程**
1. 用户拍摄车牌照片
2. 调用百度OCR车牌识别API
3. 返回识别结果(车牌号字符串)
4. 自动填充到搜索框并触发查询

**识别要求**
- 使用百度OCR车牌识别能力
- 识别失败时允许用户重新拍照或手动输入

### 4.4 新增车辆规则

**新增流程**
1. 用户选择车辆类别(汽油车辆/柴油车辆/LNG车辆)
2. 用户填写对应表单字段
3. 用户点击保存按钮
4. 系统将数据保存至对应数据表
5. 保存成功后返回查询页面

**新增规则**
- 车牌号为必填字段
- 车牌号不得与数据库中已有车牌号重复
- 序号字段自动生成或由用户填写

### 4.5 编辑车辆规则

**编辑流程**
1. 用户在查询结果页面点击编辑按钮
2. 系统跳转至编辑页面，预填充当前车辆信息
3. 用户修改字段内容
4. 用户点击保存按钮
5. 系统更新数据库中该车辆信息
6. 保存成功后返回查询结果页面

**编辑规则**
- 允许修改任意字段
- 车牌号修改后不得与其他车辆重复
- 车辆类别不可修改

### 4.6 删除车辆规则

**删除流程(查询结果页面)**
1. 用户在查询结果页面点击删除按钮
2. 系统弹出二次确认弹窗，提示「确认删除该车辆信息？」
3. 用户点击确认按钮
4. 系统从数据库中删除该车辆记录
5. 删除成功后返回查询页面

**删除流程(删除车辆页面)**
1. 用户在首页点击删除车辆按钮，进入删除车辆页面
2. 用户输入车牌号(或部分车牌号)
3. 系统自动查询并展示车辆完整信息
4. 用户确认信息无误后，点击删除按钮
5. 系统弹出二次确认弹窗，提示「确认删除该车辆信息？」
6. 用户点击确认按钮
7. 系统从数据库中删除该车辆记录
8. 删除成功后返回查询页面

**删除规则**
- 删除操作不可撤销
- 删除后数据从数据库中永久移除
- 删除后再次搜索该车牌号将无法查询到结果

### 4.7 设计风格规范

**颜色规范**
- 背景色：浅灰(#F4F5F7)
- 主色调：效率蓝(#0052CC)
- 警告色：警告橙(#FF5630)

**样式规范**

- 无渐变效果
- 工业理性风格

## 5. 异常与边界情况

| 场景 | 处理方式 |
|---|---|
| 拍照识别失败 | 提示「识别失败，请重新拍照或手动输入车牌号」 |
| 未输入车牌号直接搜索 | 提示「请输入车牌号」 |
| 查询不到车辆信息 | 显示「未找到该车牌号对应的车辆信息」 |
| 网络异常导致查询失败 | 提示「网络异常，请稍后重试」 |
| 数据库连接失败 | 提示「系统异常，请稍后重试」 |
| 相机权限未授权 | 提示「请授权相机权限以使用拍照识别功能」 |
| 新增车辆时车牌号重复 | 提示「该车牌号已存在，请检查后重新输入」 |
| 新增车辆时必填字段为空 | 提示「请填写车牌号」 |
| 编辑车辆时车牌号修改为已存在车牌号 | 提示「该车牌号已存在，请检查后重新输入」 |
| 删除车辆时网络异常 | 提示「删除失败，请稍后重试」 |
| 保存车辆信息时数据库异常 | 提示「保存失败，请稍后重试」 |
| 删除车辆页面未输入车牌号 | 不展示车辆信息，删除按钮不可点击 |
| 删除车辆页面查询不到车辆 | 显示「未找到该车牌号对应的车辆信息」，删除按钮不可点击 |

## 6. 验收标准

1. 用户打开应用，进入查询页面
2. 用户点击删除车辆按钮，进入删除车辆页面
3. 用户输入车牌号，系统自动查询并展示车辆完整信息
4. 用户确认信息无误后，点击删除按钮
5. 系统弹出二次确认弹窗，用户点击确认按钮
6. 系统删除车辆信息，返回查询页面并提示「删除成功」
7. 用户再次输入该车牌号进行查询，系统提示「未找到该车牌号对应的车辆信息」
